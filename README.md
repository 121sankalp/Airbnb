# 📌 BookMyStay – Scalable Monolithic Airbnb Clone  

A **hotel booking platform** inspired by **Airbnb**, built on a **monolithic architecture** with **modular system design principles**.  
BookMyStay is designed for **scalability, reliability, and real-time pricing optimization**, enabling users to search, book, and manage stays while hotel managers handle inventory seamlessly.  

---

## 🚀 Features  
- 🔑 **User Features** – Search hotels, book rooms, add/delete guests, secure payments  
- 🛠️ **Admin / Hotel Manager Features** – Add, delete, activate/deactivate hotels, manage rooms & bookings  
- 📊 **Dynamic Pricing Engine** – Occupancy, urgency, holiday & discount-based strategies (Decorator Pattern)  
- 🛡️ **Security** – JWT-based authentication & role-based authorization (User, Guest, Manager, Admin)  
- 💳 **Payments** – Stripe API integration for secure real-time transactions  
- ⚡ **Optimized APIs** – Hotel & room search APIs improved by **40% response time reduction**  
- 🏗️ **System Design Principles** – SOLID, modular layers (Entity → Controller → Service → Repository)  

---

## ⚙️ Tech Stack  
- **Backend:** Java, Spring Boot (Monolithic)  
- **Database:** PostgreSQL / SQL  
- **Authentication:** JWT-based secure API access  
- **Design Patterns:** Strategy Pattern, Decorator Pattern  
- **Payments:** Stripe API  
- **Architecture Principles:** SOLID, modular monolithic design  

---

## 📂 System Modules  
- 👤 **User Module** – Search hotels, book rooms, add/delete guests, manage bookings  
- 🏨 **Hotel Manager Module** – Manage hotels, activate/deactivate hotels, handle rooms & bookings  
- 💳 **Payment Module** – Secure transactions via Stripe, real-time status updates  
- 📊 **Dynamic Pricing Module** – Revenue optimization through occupancy, urgency & seasonal strategies  

---

## 🔑 Why Monolithic with Design Principles?  
- ✅ Ensures **simpler deployment & management** compared to microservices  
- ✅ Built with **SOLID principles & modular design** → easy to extend, maintain, and scale  
- ✅ **Design Patterns (Strategy + Decorator)** → Plug-and-play business logic & real-time pricing flexibility  
- ✅ Future-ready → Can evolve into microservices when scaling demands increase  

---

## 📌 Key Highlights  
- 🏗️ **Modular Monolithic Architecture** with clear separation of concerns  
- ⚡ **40% faster response times** for hotel & room search APIs  
- 💳 **Reliable Payments** – Stripe integration with booking confirmation  
- 🔐 **Advanced Security** – JWT-based role & access control  
- 📊 **Dynamic Pricing** – Boosted revenue with real-time adaptive pricing strategies  
- 🚀 **Extensible Design** → Easy onboarding of new features
